# コンフィグ

- テーマ: どれほど優れた力を持っていても、一人ですべてを背負うのではなく、誰かを信じて共に生きることで初めて守れるものがある。
- コンセプト: 中世ヨーロッパ風の諸侯と教会が争う世界を舞台に、魔法の常識を次々と覆す青年の天才魔法使いが、彼を危なっかしい弟のように扱う女騎士と旅をしながら各地の魔法事件を解決し、やがて王国を揺るがす大事件へ巻き込まれていく魔法冒険譚。
- ログライン: 他人を頼らず魔法だけで何でも解決してきた若き天才魔法使いは、王国各地で頻発する不可解な魔法事件の真相を突き止めるため女騎士と旅に出るが、やがて自分一人の力では救えない危機に直面し、反発しながらも惹かれていく彼女を信じて戦うことを迫られる。
